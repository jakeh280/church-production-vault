# Sunday startup

> [!warning] Not yet verified, confirm before relying on this live.

- **Who does this:** whoever is on audio, first person in the booth
- **When:** 45 minutes before rehearsal
- **How long it takes:** about 15 minutes if nothing is wrong

## Before you start

House lights up. Nobody on stage yet. You need the booth key and the wireless drawer open.

## Steps

1. Power the console first and leave it: it needs about ninety seconds before it passes audio, and everything else waits on it. See [[Audio-System]].
2. Power amps on, then the stage boxes.
3. Recall the Sunday scene.
4. Pull the handhelds from the drawer, fresh batteries in all four, and check each one for RF and audio at the back of the room, not at the booth. Log anything odd on [[Handheld-Wireless-TX]].
5. Bring up the stream encoder and confirm it sees audio *before* the band arrives. The matrix send is post-fader, so a muted house is a silent stream. See [[No-Audio-In-Stream]].
6. Talk to the person on video. Confirm they're up and that you both have the same running order.

## If something goes wrong

Most startup problems are power sequence, something came up before the thing it depends on. Powering down and back up in order fixes more than it should. If the stream has no audio, go straight to [[No-Audio-In-Stream]].
